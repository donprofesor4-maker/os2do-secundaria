# Aula OS · Segundo de secundaria

Escritorio educativo independiente de OS2 de primaria y OS3 de secundaria.

## Aplicaciones
- NEXO: 24 retos de lógica aplicada a Matemáticas, Español, Ciencias, Geografía y Formación cívica.
- Cuaderno: escribir reglas y descargar documentos TXT.
- Mis archivos: documentos guardados localmente en el navegador.
- Ruta de aprendizaje: seis fases hacia programación y especificaciones para IA.

## Accesibilidad de uso
Botones grandes, primera misión guiada, pistas sin penalización, reordenamiento con botones (sin arrastrar), recorrido paso a paso y acceso móvil al programa. Código JavaScript y datos propios se muestran como opciones.

## Evidencia de aprendizaje
Compara varios casos, incluidos valores frontera. Las estrellas representan los resultados de las pruebas del juego; no equivalen a una evaluación completa de comprensión. Las reflexiones se guardan para revisión docente. La vista docente abre todos los retos sin modificar el avance del alumno.

Los retos 21–24 construyen peticiones con entrada, regla, caso especial, salida y ejemplos. Es una simulación local; no se conecta a una IA ni envía datos.

## Uso
Abrir index.html o servir esta carpeta con un servidor estático. Guardado en localStorage: documentos y NEXO usan claves independientes. Los navegadores compartidos comparten datos; para llevar evidencia a otro equipo, descargar la bitácora y los TXT. La bitácora TXT no restaura automáticamente el progreso.

No hay cuentas, anuncios, calificaciones escolares oficiales ni conexión con el sistema de archivos del equipo. Todos los recursos se incluyen en la carpeta. Las reglas simplificadas de los ejercicios se explican en cada reto.
